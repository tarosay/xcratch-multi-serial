Xcratch 拡張機能

マルチシリアル接続

USB でつないだ micro:bit を何台も同時につなぎ、 それぞれから届くデータを Scratch のブロックで受け取れます。 インストールは要りません。

Xcratch で開く →
押すと拡張機能を読み込んだ状態で Xcratch が開きます（Chrome / Edge / Firefox）。

できること

8 つまで同時に受信 ボーレートの指定 受け取ったとき 1 行読む・最新の行 名前と値を読む 区切りの設定 数値の取り出し リストに入れる

つないだポートは「シリアル通信 1」〜「シリアル通信 8」の番号で区別します。 この番号は COM の番号とは関係ありません。 どのポートを何番にするかは、ブラウザが出すダイアログで選びます。

micro:bit 2 台を同時につなぎ、それぞれから受信できることを確認しています （3 台以上は確かめていません）。

使い方

  1. Chrome・Edge・Firefox のどれかで Xcratch を開きます。 上の「Xcratch で開く」を押すと、拡張機能を読み込んだ状態で開きます。 自分で読み込むときは、Xcratch の「拡張機能を追加 → Extension Loader」に 次の URL を入れます。 https://tarosay.github.io/xcratch-multi-serial/multiserial.mjs
  2. ブロックを組みます。 micro:bit 2 台から受け取る例です。 
    緑の旗が押されたとき
  シリアル通信 (1) を ボーレート (115200) で開始する
  シリアル通信 (2) を ボーレート (115200) で開始する

シリアル通信 [1] で受け取ったとき
  変数1 を ((シリアル通信 (1) の最新の行) の中の数値) にする
  シリアル通信 (1) の受信データを捨てる
  3. 緑の旗を押して、ダイアログで 1 台目を選びます。 続けて画面のどこかをクリックすると、2 台目のダイアログが出ます。
⚠ 1 回のクリックで出せるダイアログは 1 つだけです。 2 つ目の「開始する」は「画面をクリックしてください」で待っているので、 画面をクリックしてください。ブラウザの決まりによるものです。

うまくいかないときは、シリアル通信 (1) の状態 を「言う」などで表示すると、 理由が分かります。

micro:bit の側

MakeCode の シリアル通信 1行書き出す か シリアル通信 名前と値を書き出す で送ります。 名前と値を書き出す で送った値は、 シリアル通信 (1) の [x] の値 で名前を指定して読めます。

送る間隔は 50 ミリ秒以上（1 秒に 20 回以下）を目安にしてください。 ボーレートは MakeCode の既定の 115200 です。

⚠ MakeCode の シリアル通信 で日本語を送ると、文字化けします。 英数字で送ってください。

必要なもの

  • USB でつなぐシリアル機器（micro:bit など）と USB ケーブル
  • Chrome・Edge、または Firefox 151 以降（パソコン版）。 Web Serial API を使います。Safari は対応していません（2026年10月時点）

それ以外に必要なものはありません。インストールもアカウントも不要です。

困ったとき

micro:bit をつないだまま Xcratch を閉じると、しばらくして micro:bit からの送信が 止まることがあります。 micro:bit の電源を切って入れ直すと戻ります。

受信中の番号で「開始する」が動いても、何もしません。 ボーレートを変えるときは、先に「終了する」を動かしてください。
